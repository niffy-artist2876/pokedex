# Pokédex Team Lab: web app

Next.js 16 front end and API layer for the Pokedex database. Setup, environment
variables and the feature list are in the [main README](../README.md).

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```

It reads the repository-root `.env` (`APP_DATABASE_URL`, `SESSION_SECRET`).
